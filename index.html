Ketentuan Penggunaan Lisensi

Harap perhatikan syarat dan ketentuan layanan kami demi kenyamanan bersama.

1 License = 1 IP VPS

Satu pembelian lisensi hanya berlaku eksklusif untuk satu alamat IP publik VPS. Tidak dapat digabung atau digunakan bersamaan untuk IP lain.

Aturan Ganti IP VPS

Penggantian IP diperbolehkan jika VPS mengalami kerusakan/ganti provider di masa aktif, dengan konfirmasi terlebih dahulu kepada admin.

Wajib Fresh Install OS

Pastikan VPS dalam keadaan bersih dari panel lain atau skrip lama untuk menghindari konflik port dan dependensi sistem.

Garansi & Dukungan

Garansi penuh lisensi aktif selama masa berlangganan, serta bantuan teknis langsung jika terjadi kendala pada skrip.

Panduan & Cara Instalasi

Ikuti tahapan penting di bawah ini sebelum menjalankan script pada VPS Anda.

Peringatan Penting Sebelum Install!

Pastikan VPS Anda menggunakan sistem operasi Fresh Install (bersih tanpa panel lain, skrip lama, atau konfigurasi web server yang bertabrakan). Kesalahan pada sistem yang sudah terisi aplikasi lain dapat menyebabkan kegagalan instalasi skrip.

Wajib Memiliki & Mempointing Domain!

Sebelum instalasi, Anda wajib menyiapkan domain sendiri (Cloudflare/ClouDNS) dan mengarahkan (pointing) DNS A record domain tersebut ke alamat IP VPS Anda untuk pembuatan sertifikat SSL.

01

Pointing Domain

Arahkan domain ke IP VPS Anda.

02

Daftar Lisensi

03

Login SSH

Pertanyaan yang Sering Diajukan (FAQ)

Temukan jawaban cepat seputar layanan dan penggunaan autoscript kami.

Berapa lama proses aktivasi lisensi setelah pembayaran?

Proses aktivasi sangat cepat, biasanya hanya membutuhkan waktu 1 hingga 5 menit setelah Anda mengirimkan bukti transfer dan alamat IP VPS kepada admin.

Apakah autoscript ini aman dari carding atau malware?

Sangat aman. Skrip kami murni dirancang untuk manajemen server tunneling, bersih dari kode berbahaya (backdoor), dan transparan tanpa menyedot resource VPS Anda secara berlebihan.

Apakah ada bantuan jika saya mengalami kendala instalasi?

Tentu saja! Setiap pembelian lisensi sudah termasuk layanan support penuh. Jika Anda mengalami error saat instalasi, admin siap membantu mengecek atau memandu via WhatsApp.

VPS provider apa saja yang direkomendasikan?

Script kami mendukung hampir semua cloud provider populer seperti DigitalOcean, Linode, AWS, Vultr, Biznet GIO, Herza Cloud, Leaseweb, dan provider VPS lokal maupun internasional lainnya.
