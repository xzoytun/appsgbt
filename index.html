Autoscript install VPS, tinggal sewa per IP.

Zoy Tunneling menyewakan akses autoscript untuk setup VPS tunneling dalam sekali jalan. Support Debian 10–13 dan Ubuntu 20, 22, 24, 25. Bayar per IP, bukan langganan ribet.

// cara pakai

3 langkah install

01
Hubungi admin & lakukan pembayaran
Pilih durasi sewa (1/2/3 bulan), transfer sesuai harga, admin akan aktifkan akses IP kamu.
02
Login ke VPS via SSH
Masuk sebagai root ke VPS Debian atau Ubuntu yang sudah didukung.
03
Jalankan command install
Copy paste command di bawah ini, tunggu proses selesai, dan VPS siap dipakai.
install.sh 
sysctl -w net.ipv6.conf.all.disable_ipv6=1 && \
sysctl -w net.ipv6.conf.default.disable_ipv6=1 && \
apt update --allow-releaseinfo-change && \
apt upgrade -y && \
apt install -y curl wget unzip sudo gnupg lsb-release build-essential libcap-ng-dev libssl-dev libffi-dev python3 python3-pip && \
curl -fsSL -O https://raw.githubusercontent.com/joytun21/schaya/main/mahbub && \
chmod +x mahbub && \
./mahbub
Jalankan sebagai root pada VPS yang masih bersih (fresh install) untuk hasil terbaik. Pastikan akses IP kamu sudah aktif dari admin sebelum menjalankan script.
// faq

Pertanyaan umum

Apakah harga berlaku untuk 1 IP atau bisa dipakai banyak server?

Harga di atas berlaku per 1 IP VPS untuk masa aktif sesuai durasi yang dipilih. Kalau butuh banyak IP sekaligus, hubungi admin untuk harga paket.

Bagaimana kalau OS VPS saya tidak ada di daftar?

Autoscript ini dioptimalkan untuk Debian 10–13 dan Ubuntu 20/22/24/25. Untuk versi di luar itu, tanyakan dulu ke admin sebelum instalasi.

Apakah ada garansi kalau script gagal jalan?

Kendala teknis saat instalasi bisa langsung dikonsultasikan ke admin melalui WhatsApp untuk dibantu troubleshoot.

Bagaimana cara memperpanjang masa aktif IP?

Hubungi admin sebelum masa aktif habis, sebutkan IP yang ingin diperpanjang dan pilih durasi baru.
