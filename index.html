Pertanyaan Umum (FAQ)

Apakah masa aktif berlaku untuk multi-server?

Satu harga paket berlaku untuk 1 alamat IP VPS spesifik. Jika Anda ingin mengaktifkan di server berbeda, diperlukan pendaftaran IP baru.

Bagaimana jika OS VPS saya berbeda dari daftar?

Autoscript ini sudah dirancang khusus untuk kompatibilitas optimal di Debian dan Ubuntu versi tersebut. Konsultasikan terlebih dahulu jika memakai OS lain.

Apakah ada bantuan jika proses instalasi gagal?

Tentu, Anda bisa langsung menghubungi admin via WhatsApp untuk mendapatkan bantuan penanganan masalah teknis (*troubleshooting*).
